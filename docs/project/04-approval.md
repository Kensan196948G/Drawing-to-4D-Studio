## 2. 構成上の判断（設計と同時に確認する事項）

構想案の Phase 1「完全オフライン Standalone」と、開発指示の「Cloudflare Preview / ローカルPostgreSQL」を両立するため、次の二層構成を採る。

1. 製品の中核はオフラインSPA（`file://` で動作、図面を送信しない）。
2. 検証環境のみ、SPA＋ローカルAPI＋PostgreSQL（サンプルカタログ・辞書共有・任意のサーバ保存）。
3. 本番環境・本番DBは対象外。

この判断は設計承認の選択肢1に含める。異なる場合は選択肢2で指定を受ける。
