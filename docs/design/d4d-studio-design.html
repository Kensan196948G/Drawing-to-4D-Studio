1. 目的・利用者・解決課題

目的

手元の2D施工計画図と工程表から、施工順序が伝わる4Dを短時間で作り、発注者協議・社内説明・地元説明に使えるようにする。

利用者

施工計画担当者1名。CADの操作には慣れているが、Navisworks等の4D専用ソフトは日常的に使わない。PCブラウザ（1280×800以上）で利用する。

解決課題

  • 2D図面と工程表を頭の中で重ねる負担を減らす。
  • 専用ソフトの3Dモデリングと工程紐付けの手間を省く。
  • 工程変更を4Dへすぐ反映できるようにする。

この設計が守ること

  • 完全オフライン: 図面はブラウザ内だけで処理し、外部送信しない。
  • 半自動: 推定は下書き。確定は必ず担当者が行う。
  • 概略でよい: 説明と合意形成のための4D。数量・干渉確認には使わない。
  • 1画面1判断: 取り込み → 工種 → 高さ → 3D → 4D の順に迷わない。

2. 主要フロー（1〜3）

F1 取り込みから4D再生まで（中核）

DXF + CSV 取り込み→ 工種の確認・修正→ 標高の確認・修正→ 3D生成→ 4D再生・日付移動・視点変更
項目内容
開始条件DXF（平面図・断面図）と工程表CSVが手元にある。サンプルでも可。
操作2ファイルを置く → 工種候補を確認 → 標高を確認 → 3D生成 → 再生。
期待結果工程表の日付に応じて部材が順に現れ、視点を変えられる。
保存データ図面（要素）・工程表・工種割当・標高・辞書（ブラウザ保存）。
エラー時解析不能な要素は除外し、理由を警告として残す。図面全体の失敗は再取込を促す。
受入サンプルで 8工種・29部材が生成され、2027/04〜2028/03 の範囲で再生できる。

F2 保存と再開（辞書の学習を含む）

保存→（別セッション）開く→同じ4Dを再現
項目内容
開始条件F1を一度完了している。
操作ヘッダ「保存」→ 案件名を確認 → 保存。次回「開く」で一覧から選択。
期待結果工種・標高・工程・辞書が復元され、同じ4Dが再生できる。
保存先ブラウザ（localStorage）。API接続時はローカルPostgreSQLにも保存できる（任意）。
エラー時容量超過は ERR-107。API失敗は ERR-111 とし、ブラウザ保存は継続する。
受入保存→再読込で部材数・工種・標高が一致する。

F3 辞書の改善（同じ書き方の図面を次から自動化）

手動で工種を修正→「このレイヤ名を辞書に登録」→次回の図面で自動割当

修正結果は辞書（exact一致・優先度200）へ追加し、同じレイヤ名の図面では信頼度100%で自動割当します。辞書は保存データに含め、API接続時はローカルDBの辞書へ同期できます。

2 工種の割り当て

レイヤごとに工種を確定します。推定は下書きです。

レイヤCAISSON5要素93%確認
レイヤLayer31要素65%確認
除外DIM4要素寸法

骨格

  • 上部バー（56px）: ロゴ、オフラインバッジ、KPI、保存・開く・テーマ。
  • 左ナビ（212px）: 5ステップ、各ステップの状態、範囲の注記。
  • 作業領域: 最大幅 1080px。カード単位で「読む→決める→次へ」。
  • 下部: ステップ内の主操作（戻る／次へ）を右寄せ。

ナビゲーション規則

  • 現在ステップは番号を塗り、完了は緑のチェック、要確認は橙の点。
  • 進む条件を満たさないステップは aria-disabled="true" とし、理由を表示。
  • ファイル未取込で SCR-02 以降を開いた場合は Empty 状態を表示し、SCR-01 へ戻す。
  • ブラウザの戻る/進むはステップ移動に連動（URLハッシュ #step-2）。

6. SCR-01 取り込み

画面の構成

  • ドロップゾーン: DXFと工程表CSVを同時に受け付ける。複数ファイル可。
  • サンプル: 岸壁施工計画図（架空）と工程表を1クリックで読み込む。
  • 対応形式表: DXF=対応、CSV=対応、DWG=変換、SXF/PDF/Excel=第2段階。
  • 読み込み結果: 線・輪郭／円／文字／レイヤの件数、単位、範囲、警告。
  • 図面プレビュー: SVG。ドラッグで移動、ホイールで拡大、フィット。

操作とフィードバック

  • DXFドロップ → 進捗バー → 件数とプレビューを表示。
  • CSVドロップ → 工程表の行数・期間・不良行を表示。
  • DXFのみ／CSVのみでも次へ進めるが、SCR-02/03 で不足を明示する。
  • サンプル読込は「サンプル図面（架空）」バナーを出す。
図面の内容はこのパソコンの中だけで処理します。サーバへは送信しません。

状態

状態表示次の操作
Emptyドロップゾーンと対応形式表のみ。KPI は 0。ファイル選択 / サンプル
Loading進捗バー（解析中）。ボタンは無効。待機
Error赤のインラインパネルに ERR-102 と理由。入力は保持。再選択
Warning橙のリスト（未対応要素、単位換算、閉じていない輪郭）。確認して次へ
Success件数サマリとプレビュー。緑のトースト「DXFを読み込みました」。SCR-02 へ

7. SCR-02 工種の割り当て

レイヤ単位に「要素数・推定候補・確からしさ・確認状態」を1行で示します。推定は下書きであり、確定は担当者が行います。

列内容操作
レイヤレイヤ名（mono）、要素数、文字注記の抜粋クリックでプレビュー強調
工種候補3件 + 「未割当」+「対象外」セレクトで確定
確からしさ0–100%。根拠（レイヤ名/コード/注記/形）をツールチップ—
確認チェックボックス確定 / 未確定
辞書手動修正時に「このレイヤ名を辞書に登録」オン/オフ（既定オン）

一括操作

  • 信頼度80%以上を一括確定: 未確定かつ推定候補ありの行だけ。
  • 未確定のみ表示: フィルタ。残件数をナビに表示。
  • 対象外を除く: DIM・法線・断面・文字レイヤは既定で除外。

進む条件

3D対象レイヤがすべて「確定」または「対象外」になっていること。未確定が残る場合は DLG-02 で確認し、そのまま進むこともできる（未確定は3D化されない）。

推定の根拠表示

根拠例初期信頼度
レイヤ名の工種コード4D_050_上部工98%
レイヤ名のキーワードCAISSON / MOUND88–96%
近傍の文字注記Layer3 内の「裏込石」65–67%
同じ形の繰り返し同形の四角が5つ50%
辞書（学習済み）前回修正したレイヤ名100%
紫は「人の確認が必要」を意味します。推定が高くても、確定操作なしに3D化しません。

8. SCR-03 高さの付与

平面図には高さがありません。断面図の標高注記を候補として示し、工種ごとに天端・底面を確定します。

標高表

列内容
対象チェックボックス（準備工・片付けは既定オフ）
工種コード + 名称
天端 / 底面数値入力（m、0.01刻み、矢印キー可）
進行方向延長方向 / 1つずつ / 下から積む / 即時
根拠初期値 / 注記 / 手動

サンプルでは断面図から10件の注記を抽出します（例: ケーソン 天端 +2.0、床掘底 -13.0）。

注記パネル

  • 抽出した注記を「ラベル / 値 / 対応工種 / 根拠」で一覧表示。
  • 「すべて反映」で対応工種の天端・底面へ反映。
  • 個別の「反映」も可能。反映後は根拠が「注記」に変わる。
  • 対応工種が決められない注記は「未対応」とし、自動反映しない。
天端 ≦ 底面、または高低差100m超はエラー。赤字で理由を出し、次へ進めません。

11. DLG-01 保存・開く／DLG-02 確認

DLG-01 保存・開く

  • 保存: 案件コード・案件名・説明を入力。既定値は「岸壁工事（サンプル）」。上書き確認あり。
  • 開く: ブラウザ保存の一覧（更新日時・部材数）。API接続時は「サーバの案件」タブ。
  • 削除は確認ダイアログ（DLG-02）を挟む。
  • 保存容量が5MBに近い場合は警告。超過時は ERR-107。

DLG-02 確認

  • 上書き保存、削除、未確定のまま3Dへ進む、の3用途。
  • 本文は1文で「何が起きるか」を書き、主ボタンは破壊的操作のみ赤。
  • Esc・背景クリックで閉じる。フォーカスは主ボタンへ。

14. レスポンシブ・アクセシビリティ

端末

  • PC中心。1280×800以上を標準。
  • 1200px以下: 左ナビ 180px、KPIは4件まで。
  • 980px以下: ナビを上部の横スクロールタブへ。表は横スクロール。
  • スマートフォン最適化は対象外（表示崩れしないことのみ確認）。

アクセシビリティ（WCAG 2.1 AA 相当）

  • コントラスト 4.5:1 以上。状態は色＋文字で示す。
  • キーボードだけで F1 を完了できる。可視フォーカス、Escで閉じる。
  • ダイアログは <dialog> とフォーカストラップ。
  • フォームは label と紐付け、エラーは aria-describedby。
  • トーストは aria-live="polite"。3Dキャンバスには代替テキストと操作説明。
  • prefers-reduced-motion で再生アニメーションを抑制。

15. エラーコード

コード意味表示場所回復
ERR-101未対応のファイル形式SCR-01 インラインDXF/CSVを選び直す
ERR-102DXFの解析に失敗SCR-01 インライン別のDXF、またはASCII DXFで保存
ERR-103要素数が上限（20万）超過SCR-01 インライン図面を分割
ERR-104工程表が空、または日付を読めないSCR-01/03列名・日付形式を確認
ERR-105工程表の行に不備（終了<開始など）SCR-01 警告リスト該当行を修正して再取込
ERR-106工程表と部材の工種が未対応SCR-04 警告工種コード/名称を合わせる
ERR-107ブラウザ保存の容量超過DLG-01案件を削除、またはAPI保存
ERR-108APIに接続できないヘッダの状態オフライン継続
