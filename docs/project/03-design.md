## 4. PoC からの変更点（WHY）

| 変更 | 理由 |
| --- | --- |
| 4ステップ → 5ステップ | 工程表を取込みに統合し、3D生成と4D表示を分けた。生成結果の警告を確認してから再生するため。 |
| 工種表に「根拠」列を追加 | 推定の理由が見えないと担当者が判断できない。確からしさの数字だけにしない。 |
| 辞書登録のオン/オフ | 誤修正を辞書に入れないための制御。既定オン、行単位で解除可能。 |
| 標高注記パネルを追加 | 断面図の注記を一括反映できるようにし、手入力を減らす。 |
| 開いた輪郭の自動補正を警告表示 | エプロン舗装の0.5mの隙間のような実例に対応。黙って閉じない。 |
| API状態をヘッダに表示 | オフラインでも動くことを明示し、通信エラーで止めない。 |
| 保存形式に辞書を含める | F3（辞書の改善）を案件と一緒に再現するため。 |

## 6. 実装後の比較（2026-11-18）

画面証拠: `docs/evidence/screens/01-import.png` 〜 `06-save-dialog.png`

| 画面 | 仕様 | 実装 | 差異・理由 |
| --- | --- | --- | --- |
| SCR-01 | ドロップゾーン・統計・プレビュー・警告 | 実装済み。サンプル時に「サンプル図面（架空）」バナーを追加 | 仕様のバナー要件を実装。プレビューは断面図も含むため全体表示 |
| SCR-02 | 候補3件＋未割当＋対象外 | 候補を先頭に置き、**全工種**も選択可能。辞書登録は行単位 | 候補が無い未知レイヤでも工種を選べないと確定できないため追加（設計の意図を満たす拡張） |
| SCR-03 | 標高表・注記パネル | 実装済み。表の幅を広げ、注記はスクロール | 可読性のためグリッド比を変更 |
| SCR-04 | 部材数・警告・3Dプレビュー | 実装済み | 仕様どおり |
| SCR-05 | 4D・日付・再生・視点・ガント・部材一覧 | 実装済み。部材一覧は工種順にソート | 一覧の見通し向上 |
| DLG-01 | 保存・開く・削除 | 実装済み（ブラウザ＋サーバ） | 仕様どおり |
| DLG-02 | 未確定のまま進む・削除確認 | 実装済み | 仕様どおり |
| 全体 | tech-utility + human-approachable | トークン・角丸・表密度を反映 | ダークテーマ、印刷、reduced-motion も実装 |

**未実装・差異として残すもの**: MP4書き出し（対象外）、サーバ案件の削除（API未実装）、PDF/Excel等の形式（第2段階）、方式B（Backlog）。
