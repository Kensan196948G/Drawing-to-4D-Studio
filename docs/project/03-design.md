## 4. PoC からの変更点（WHY）

| 変更                           | 理由                                                                                       |
| ------------------------------ | ------------------------------------------------------------------------------------------ |
| 4ステップ → 5ステップ          | 工程表を取込みに統合し、3D生成と4D表示を分けた。生成結果の警告を確認してから再生するため。 |
| 工種表に「根拠」列を追加       | 推定の理由が見えないと担当者が判断できない。確からしさの数字だけにしない。                 |
| 辞書登録のオン/オフ            | 誤修正を辞書に入れないための制御。既定オン、行単位で解除可能。                             |
| 標高注記パネルを追加           | 断面図の注記を一括反映できるようにし、手入力を減らす。                                     |
| 開いた輪郭の自動補正を警告表示 | エプロン舗装の0.5mの隙間のような実例に対応。黙って閉じない。                               |
| API状態をヘッダに表示          | オフラインでも動くことを明示し、通信エラーで止めない。                                     |
| 保存形式に辞書を含める         | F3（辞書の改善）を案件と一緒に再現するため。                                               |

### 6.1 UI 改善（2026-11-19）— 分かりやすさ・アイコン・動き

「分かりやすいUI」「アイコンと動的アニメーションを積極的に多用」という利用者指示にもとづく実装。
**画面ID（SCR-01〜05 / DLG-01・02）・状態名・エラーコードは変更していない。**

| 領域             | 変更内容                                                                                                                                                | 意図                                             |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| ステップナビ     | 各ステップを意味のアイコン（取り込み=upload / 割当=layers / 高さ=ruler / 3D=cube / 4D=play）で表示。完了はチェックに置換。`n / 5 完了` の進捗バーを追加 | 番号だけより「何をする段階か」が一目で分かる     |
| 現在地           | 作業画面の先頭に `STEP n / 5` の進捗ストリップを追加（`role="progressbar"`）                                                                            | サイドバーを見なくても現在地と残りが分かる       |
| 完了判定         | 完了は**順番に積み上げ**（前段が未完了なら後段は完了にしない）。いま開いているステップは「完了」ではなく現在地として表示                                | 後続工程だけが緑チェックになる誤解を防ぐ         |
| 集計（KPI）      | 各KPIにアイコンを付与。値の変化は数え上げ＋強調アニメーション                                                                                           | 押した操作が数値に反映されたことが分かる         |
| API状態          | 色付きドット＋ラベルのバッジ。オンライン時はドットが脈動                                                                                                | 接続状態を文字より先に認知できる                 |
| 工種の割り当て   | 確からしさを**メーター（バー＋%）**で表示。色は 80%以上=緑 / 50%以上=橙 / 未満=赤                                                                       | 目で確かめる優先順位が分かる                     |
| 空・読み込み     | 空状態にアイコン（浮遊アニメーション）、読み込みにシマー                                                                                                | 停止ではなく「待ち」「未着手」であることを伝える |
| ダイアログ       | 見出しアイコン、入場アニメーション、Toast はスライドイン＋残時間バー                                                                                    | 何の確認か、いつ消えるかが分かる                 |
| 3D/4D            | ガントバーの伸長、現在日付マーカーの脈動、再生中ボタンの状態属性                                                                                        | 時間の進みが視覚的に追える                       |
| 操作の手応え     | ボタン・行・凡例のホバー/押下、クリック位置からの波紋                                                                                                   | 反応していることが伝わる                         |
| アクセシビリティ | `prefers-reduced-motion: reduce` で全アニメーションを実質無効化。`aria-current="step"`、`role="progressbar"`、アイコンは `aria-hidden`                  | WCAG 2.1 AA 相当を維持                           |

検証: `pnpm typecheck` / `pnpm lint` / `pnpm build` 成功、E2E 9件成功（`pnpm exec playwright test`）。
画面証拠は `docs/evidence/screens/01-import.png` 〜 `06-save-dialog.png` を再撮影して更新。
