# Limitations — 既知の制限と将来対応

版: v1.0（2026-11-18）

## 1. 機能の制限

| # | 制限 | 影響 | 将来対応 |
| --- | --- | --- | --- |
| L-01 | 3D化は方式A（閉じた平面輪郭の押し出し）のみ | 断面形状を法線に沿って押し出す方式Bは未対応。捨石マウンド等は平面形状からの近似 | 第1.5〜2段階で方式B |
| L-02 | 曲線法線・配筋・曲面は未対応 | 複雑な構造物は表現できない | Backlog |
| L-03 | 対応形式は ASCII DXF と工程表CSVのみ | SXF/PDF/Excel/DWG直接/J-LandXMLは取り込めない | 第2段階 |
| L-04 | 工種推定はキーワード辞書ベース | 辞書に無いレイヤ名は未割当。AI推定は第2段階 | 第2段階 |
| L-05 | 開いた輪郭は「0.5mまたは周長1%以内」のみ自動補正 | 大きな隙間は3D化されない。警告を表示 | 人の確認を前提に維持 |
| L-06 | 標高は断面注記または手入力 | 注記の対応工種が決められない場合は自動反映しない | 第2段階でAI補助 |
| L-07 | ブラウザ保存は約5MB | 大きな図面は保存できない（ERR-107）。再取込で復元 | IndexedDB / サーバ保存 |
| L-08 | サーバ保存の同時更新ロックなし | 2人同時編集で上書きの可能性 | revision による楽観ロック |
| L-09 | 認証は Cloudflare Access または APP_TOKEN | 未設定時はURLを知る人が利用可能 | Preview では必ず保護 |
| L-10 | スマートフォン最適化は対象外 | 表示崩れはしないが操作性は保証しない | 必要時に対応 |
| L-11 | 説明・合意形成用の概略 | 数量算出・干渉確認・BIM/CIM代替には使えない | 用途を限定して維持 |
| L-12 | 実図面での精度未検証 | 架空サンプルのみで確認 | 利用者が実図面1件で試行 |

## 2. 運用の制限

| # | 制限 | 対応 |
| --- | --- | --- |
| O-01 | 本番環境・本番DB・本番DNSは対象外 | Preview のみ |
| O-02 | CI ワークフローはAIが配置できない（ポリシー） | 利用者が `deploy/ci/ci.yml` を適用済み（2026-11-18、CI成功） |
| O-03 | Cloudflare Access の設定可否が未確認 | 不可なら APP_TOKEN + 非公開URL |
| O-04 | 実データ・社外秘図面を扱わない | 架空サンプルのみ |
| O-05 | 複数ユーザー・権限管理なし | 個人利用MVP |

## 3. 本番向け Backlog（優先順）

| 優先 | 項目 | 理由 |
| --- | --- | --- |
| P1 | 実図面1件での検証と辞書拡充 | 精度・手直し量の実測がMVPの価値判断に必要 |
| P1 | 方式B（断面押し出し） | 捨石・護岸・掘削の再現度向上 |
| P1 | Preview の Access 保護と運用監視 | 公開範囲と可用性 |
| P2 | SXF（SFC/P21）対応 | 公共工事の電子納品で必須 |
| P2 | Excel / MS Project XML | 現場の工程表運用に合わせる |
| P2 | AIによる工種推定・標高読み取り | 手直し削減 |
| P2 | 案件の版管理・共有 | 複数現場・チーム利用 |
| P3 | Blender MP4 / IFC / glTF 出力 | 高品質な説明資料・外部連携 |
| P3 | 曲線法線・配筋・曲面対応 | 複雑構造物 |
| P3 | Entra ID SSO・監査ログ | 全社運用 |
